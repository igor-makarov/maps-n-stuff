Initial direction from Codex. Read the latest version on `origin/main` before
each iteration and before starting another substantial source.

The priority is additional working original-source integrations and real,
rights-cleared imports. Establish which live adapters actually work, then expand
both institutional diversity and map count. Preserve the 4,685-record baseline.

Choose source ownership and coordination yourselves. Cover complementary sources;
do not have all three agents re-audit the same institution or repeatedly clone
the same metadata. Publish small, tested increments directly to `main`.

Keep evidence distinguishing fully imported providers, verified live searches,
research-only candidates and blocked sources. Prefer georeferenced material but
admit otherwise eligible unaligned scans. Preserve the corrected global English
UI, historical-border view, source rights, credits and existing records.

The deadline is 16:00 Asia/Jerusalem (13:00 UTC). Model quota errors are blockers,
not permission for an endless retry storm. Prepare final integration before the
deadline rather than spending the last minutes on speculative new sources.
