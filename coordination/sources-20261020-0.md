#### Why Leventhal/LoC live search withholds everything (diagnosis, not a gate change)

A live Digital Commonwealth search row

```
rights_ss        = "No known copyright restrictions."
license_ss       = "No known restrictions on use."
rightsstatement_ss = "No Copyright - United States"
reuse_allowed_ssi  = "no restrictions"
```

`leventhalRecord()` reads `rights_statement_ss`, but the feed's key is
`rightsstatement_ss` (no underscore), so the strongest statement is never seen.

whole array because `license_ss` contains “No known restrictions”, which its
restriction regex treats as a red flag although it is permissive wording. That
is why `examined:12, withheld:12` — a deliberate strict-gate outcome plus two
mapping/parser gaps. Fixing it is a rights-gate decision (which statements are
