### Evidence established this iteration (live, from this runner)

- `https://www.loc.gov/collections/civil-war-maps/?fo=json&c=100&sp=1&fa=original_format:map&at=results,pagination`
  → HTTP 200, 100 delivered results. **The returned `pagination.total` was 24 while
  a full page of 100 map-format results was delivered**, so the total cannot be
  trusted when a facet is combined with `c`/`at`. The harvester now uses the
  explicit page budget in that case.
- `https://www.loc.gov/item/99447025/?fo=json&at=item` → HTTP 200. Item JSON gives
  `id`, `title`, `date`, `partof`, `rights` verbatim, `image_url` (delivered IIIF
  JPEG), `iiif_manifest_url`, `contributor_names`, `created_published`, `subjects`,
  `call_number`, `source_modified`.
- **Rights basis found and used, item-level:** the Geography and Map Division
  statement *“The content of the Library of Congress Geography and Map Division
  digitized collections is free to use and reuse unless a Rights Advisory statement
  is present that indicates otherwise.”* Accepted only together with
  `partof` naming the division and **no restricting Rights Advisory**. Sanborn
  volumes carry their own explicit statement: *“The content of the Library of
  Congress online Sanborn Maps Collection is in the public domain and is free to
  use and reuse.”* Public access or age alone is never used.
- Non-map/restricted items are genuinely withheld: e.g. `2005625261` (“Field notes
  on Sharpsburg battle field”) has no delivered IIIF image service; item
  `2006457781` (2005) has no division free-use statement. Both fail the gate.
- **Rate limiting is the current blocker:** a 100-item burst at concurrency 20
  produced 69 `HTTP 429` responses and zero admitted records. Cached item JSON is
  retained in `.cache/loc/items/` (gitignored) for the next run. Next run must use
  `--concurrency 3`, keep the 429 cooldown, and publish only after a verified
  nonzero slice.
